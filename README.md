# AI Powered Gesture Control Platform

A real-time computer vision application that uses hand gestures to control Windows volume and screen brightness.

## Features

* Real-time hand tracking using MediaPipe
* Gesture recognition using 21 hand landmarks
* Windows volume control through hand gestures
* Screen brightness control
* Activity logging with SQLite
* Modern GUI dashboard using CustomTkinter
* Real-time camera feed with AI hand skeleton

## Technologies Used

* Python
* OpenCV
* MediaPipe
* CustomTkinter
* SQLite
* Pycaw
* Screen Brightness Control

## Supported Gestures

| Gesture               | Action             |
| --------------------- | ------------------ |
| Index Finger          | Volume Control     |
| Index + Middle Finger | Brightness Control |
| Fist                  | Mute               |
| Open Palm             | Tracking Active    |
